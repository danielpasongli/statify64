## Tabel teks lama → baru (ringkas)
| Lama | Baru |
|---|---|
| `Fitur "{d}" belum dipetakan ke variabel dataset.` | `Feature "{d}" is not mapped to a dataset variable. (AM_E_MAP_UNMAPPED)` |
| `Versi format model "{d}" tidak didukung. ...` | `The model format version "{d}" is not supported. Supported versions: 1.0, 1.1, 2.0. (AM_E_SCHEMA_VERSION_UNSUPPORTED)` |
| `Mesin prediksi gagal dijalankan. ...` | `The analysis engine failed to run. Reload the page and try again. (AM_E_WORKER)` |
| `Kolom vektor teks 'X' dan N kolom lain berisi nilai negatif...` | `Negative values were found in text vector column 'X' and N more column(s). ... (AM_E_TEXT_NEGATIVE)` |
| `{m} dari {V} kolom vektor ditemukan; {k} dianggap 0.` | `{m} of {V} vector columns found; {k} treated as 0.` |
| `Prediksi selesai: N baris diprediksi. Kolom baru: ...` | `Predictions complete: N rows scored. New columns: ...` |
| `Menerapkan model ke dataset...` | `Applying the model to the dataset...` |
| `Dataset berubah — pemetaan ... disusun ulang.` | `The dataset changed, so the Apply Model variable mapping was rebuilt.` |
| `Pengaturan Apply Model telah direset.` | `Apply Model settings have been reset.` |
| `feature_order kosong/duplikat`, `... nilai, seharusnya`, `raw tanpa recipe`, dst. (detail adapter) | `feature_order is empty/has duplicates`, `... values, expected ...`, `raw source without text preprocessing settings`, dst. |
