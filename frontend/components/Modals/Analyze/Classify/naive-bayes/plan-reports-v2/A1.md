## KEPUTUSAN TERBUKA / risiko
Semua butir di bawah sudah diputuskan pemilik (setuju sesuai rekomendasi).
1. **[DISETUJUI]** Ekspektasi test lama yang berubah secara inheren: `supportedSchemaVersions` → `["1.0","1.1","2.0"]` (`naive-bayes-adapter.test.ts`, `registry.test.ts`); `apply-model-codes.test.ts`: error 43 → 50, warning 8 → 9, regex nama kode `AM_[EWI]_[A-Z0-9_]+`.
2. **[DISETUJUI, DITUNDA KE A3]** Pesan `AM_E_SCHEMA_VERSION_UNSUPPORTED` masih "Versi yang didukung: 1.0, 1.1." (dikunci `apply-model-codes`, `useApplyModelValidation`, `apply-model-error-messages`, `apply-model-main` test). A3 memperbarui pesan dan keempat test sekaligus.
3. **[DISETUJUI]** `AM_E_TEXT_NEGATIVE` ditambahkan di A1 agar pesan Rust (A2) bisa diterjemahkan tanpa menyentuh file A3.
4. **[DISETUJUI]** `text` tidak ada pada schema 2.0 = `null`. N4 tetap WAJIB menulis `text: null` secara eksplisit.
5. **[DISETUJUI, DIIMPLEMENTASIKAN]** Vector dengan semua kolom tak terpetakan dan tanpa fitur lain tetap tidak memblokir, tetapi `validateMapping` kini menambah warning baru `AM_W_TEXT_ALL_ZERO_FILLED` (sebelum info `AM_I_TEXT_ZERO_FILLED`). Tidak dikeluarkan bila masih ada fitur lain (baris tetap diskor) atau sebagian kolom ditemukan. A3 wajib menampilkannya. Test baru: 3 di `useApplyModelMappingRulesV2.test.ts` (kini 20 test) + hitungan warning di `apply-model-codes.test.ts`.
6. **[DISETUJUI]** Validasi kolom vektor hanya menolak `STRING`; measure tidak diperiksa.
7. Severity `"info"` ditambahkan ke `ApplyModelIssue`; UI yang hanya membedakan `error` tetap aman.
8. Validasi resep di TS dangkal (config, resolved_stopwords, vocabulary == terms, panjang idf); isi konfigurasi diperiksa CORE saat `transform` (A2).
9. Pelanggaran aturan oleh agen: satu `git -C . status` tidak sengaja (time-out, tidak mengubah apa pun).
