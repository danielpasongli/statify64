## Temuan dari uji manual
- **T1 (P1, performa/memori): 17.454 kolom `VEC_*`** membuat tab Variables sangat berat, drag & drop lama, dan beberapa kali tab Chrome crash "Aw, Snap! Out of Memory". Dugaan penyebab: (a) daftar kiri dirender penuh tanpa virtualisasi (N6 risiko #5/butir B1), (b) setiap perubahan `formData` menghitung ulang peringatan/daftar, (c) payload vector berbentuk matriks padat `values[row][kolom]` (900 x 17.454 = ±15,7 juta sel; P-V5 melarang O(rows x kolom) di main thread) yang kemudian di-`postMessage` ke worker. Raw Text tidak terdampak (kosakata 1 kolom teks).
- **T2 (Uji G): DITUTUP.** Percobaan pertama memakai sel `Teks` yang terpotong (kesalahan input pemilik; terms `ma, na, say`). Setelah data diperbaiki, hasil cocok golden §6.7 (lihat checklist). Pipeline UI -> `rawTextValues` -> worker -> Rust -> export terbukti benar untuk Raw Text, dan angka golden terbukti di WASM nyata (bukan hanya test Rust). Catatan: uji ini memakai holdout 70% dengan seed `null`.
- **T3 (kualitas tokenizer, bukan bug):** kosakata Uji 2 memuat noise tweet: `#hashtag`, potongan URL (`//bit`, `//dlvr`), simbol (`&`, `-`, `->`, `<clapping`), angka (`0`, `2017`). Pemisah default Weka `[\s.,;:'"()?!]+` tidak memisah `#`, `<`, `/`, `-`. Wajar bagi mode Weka-default; memengaruhi kualitas model pada tweet.
- **T4 (Uji A):** min-std hanya mengubah hasil bila varians populasi kelas < `min_var` = (presisi/6)^2 (mis. kelas dengan nilai identik). Dataset nyata dengan varians besar memberi angka identik: perilaku benar.
- **T5 (pertanyaan pemilik, W-LEAK):** pada jalur Word-Vector, kosakata dan IDF kolom `VEC_*` dihitung STWV dari SEMUA dokumen (termasuk dokumen yang nanti jadi data uji). Jadi informasi data uji ikut membentuk fitur latih, sehingga akurasi holdout/k-fold bisa sedikit terlalu optimis (data leakage). Jalur Raw Text menghindarinya karena kosakata/IDF di-fit hanya pada data latih tiap split. Teks catatan dikunci AGENTS_V2 §3.4; kata-katanya boleh diperjelas di V1 atas persetujuan pemilik.
- **T6 (Uji 0):** angka "738 kB / 649 kB" di Network adalah ukuran transfer terkompresi; ukuran asli lebih besar. Bukan masalah (justru lebih kecil dari kekhawatiran I1).

### Uji D — Waktu k-fold raw + stemming Indonesia (BELUM DIUJI)
**Cara otomatis (tanpa menghitung dengan stopwatch).** Tempel snippet ini di DevTools > Console SEBELUM klik OK; setiap analisis akan mencetak waktu sampai worker membalas (sudah termasuk muat WASM + fit + evaluasi). Pasang ulang setelah reload halaman.
```js

  const P = Worker.prototype.postMessage;
  Worker.prototype.postMessage = function (...a) {

})();
```

(4) Ulangi k-fold 10 dengan seed sama: akurasi/confusion matrix harus identik (deterministik).
