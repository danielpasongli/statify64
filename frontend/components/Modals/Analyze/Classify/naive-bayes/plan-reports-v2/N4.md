## Ringkasan perubahan (maks. 10 butir)

1. `save.rs`: aturan schema V8. Export tetap 1.1 (kode v1 tidak disentuh, snapshot identik kecuali `trained_at`). Export jadi 2.0 hanya bila ada fitur Text atau `gaussian_minstd` (`export_requires_schema_2`). Struct §8 ditambahkan: `ExportedModelV2`, `ExportText`, `ExportFeatureV2`, `ExportedModelAny` (untagged).
2. `save.rs`: `build_export(...)` memilih jalur 1.1 atau 2.0. Export 2.0 selalu memuat `text` (eksplisit `null` bila tanpa Text) dan `likelihood`/`min_variance` per fitur.
3. `save.rs`: sumber `raw` memuat `recipe` + `raw_variable`. Sumber `vector` memuat `columns` (sama dengan `terms`). Invarian validasi Apply Model dicek saat build; galat berprefiks `NB_E_TEXT_SHAPE`.
4. `text_feature_table.rs` (baru): struktur JSON sesuai N8. Top-k lewat `nb_text::top_k`, `full` = semua term × kelas (urut term, lalu kelas), kunci `top` berurutan sesuai kelas.
5. `attribute_distribution.rs`: hanya Numeric/Categorical; `numeric_likelihood_note` memberi catatan min-std ("Gaussian (Weka min. std), min. variance = ...") dan `std_dev` memakai varians setelah min-std. Fitur Text tidak menambah baris.
6. `case_summary.rs`: `compute_text_features_summary` membuat baris `Text features` (`Raw text: '{var}' ({V} terms)` / `Word vectors: {n} columns`), catatan W-LEAK (vector), catatan "tanpa prior" (Complement K≥2).
7. `function.rs`: `trained_model` bertipe `ExportedModelAny`; `not_scored_rows` kini diekspos (top level dan di Case Processing Summary, hanya bila ada Text); `text_feature_table` dibangun dari model FINAL bila ada Text dan `Output.TextFeatureTable` aktif, dengan `k = TextTopK`.
8. `function.rs`: peringatan "schema 2.0 belum tersedia (menunggu N4)" dihapus. Bila export tidak konsisten, `run_analysis` mengembalikan `None` dengan galat `export.model`. Peringatan NotScored dipertahankan.
9. `function.rs`: semua kunci JSON baru memakai `skip_serializing_if` sehingga bentuk JSON run v1 tidak berubah.
10. `stats/mod.rs`: hanya menambah `pub mod text_feature_table;`.

## KEPUTUSAN TERBUKA / risiko

1. `raw_variable` dioper dari `function.rs` (dari `V2Context.text.raw.variable`), tidak disalin ke `TrainedTextModel`, karena `text_features.rs` di luar daftar file fase ini.
2. Bentuk JSON hasil untuk `case_processing_summary.text_features`, `case_processing_summary.not_scored_rows`, `not_scored_rows` top level, `text_feature_table`, serta `likelihood`/`likelihood_note` pada atribut Numerical ditentukan N4. Perlu dikoordinasikan dengan N8/TS.
3. `text_feature_table` hanya dibangun bila `Output.TextFeatureTable` aktif; `full` tetap lengkap berapa pun `k`.
4. Galat export berprefiks `NB_E_TEXT_SHAPE`; `run_analysis` kini bisa mengembalikan `None` bila export tidak konsisten (sebelumnya selalu `Some`).
5. `std_dev` min-std pada tabel atribut = akar varians setelah min-std (konservatif; tidak ada kolom varians baru).
6. Tes `function.rs` memakai data sintetis sendiri (bukan golden "makan nasi enak"); golden dicakup di `save.rs`/`text_feature_table.rs`.
7. Catatan N8: N8 menulis "isi `trained_model.text` agar baris Text muncul di Case Processing Summary", sedangkan N4 menyediakan `case_processing_summary.text_features` (deskripsi siap tampil + catatan). Keduanya tersedia; sisi TS harus memilih satu sumber (rekomendasi: `text_features`, fallback `trained_model.text`).
8. Peringatan NotScored masih dikirim lewat `error_collector` (konteks `evaluation.not_scored`) selain `not_scored_rows` terstruktur; tampilan ganda perlu diputuskan.
9. Validasi Apply Model hanya dicermin di tes N4 (bukan memakai kode AM). Risiko drift bila invarian AM berubah.
