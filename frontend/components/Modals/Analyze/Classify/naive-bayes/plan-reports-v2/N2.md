## Ringkasan perubahan
1. Modul baru `nb_text.rs`: enum `TextLikelihood` (`snake_case` serde), struct `TextNbParams`, fungsi `train`, `score_rows`, `top_k` dengan signature persis PLAN_V2 N2.
2. Multinomial (§6.1): `θ_ct=(N_ct+α)/(N_c+αV)`, `log_weights=ln θ`, `class_term_counts=N_ct`.
3. Bernoulli (§6.2): `p_ct=(n_ct+α)/(n_c+2α)`, `log_weights=ln p`, `log_weights_absent=ln(1−p)`, `class_term_counts=n_ct`; skor efisien `Σ_t A_ct + Σ_{x>0}(L_ct−A_ct)` (jumlah `A` per kelas dihitung sekali per panggilan).
4. Complement (§6.3, `norm=False`): `C_ct = total_t − N_ct` (dijepit ≥ 0), `L_ct=−ln θ̃`; `uses_class_prior=false` bila K ≥ 2 (K = 1 tetap memakai prior).
5. `top_k` (§6.6): `score=L_ct − mean_{c'≠c}L_c't` (K = 1: `L_ct`), urut menurun, seri → term alfabetis (byte-wise) lalu indeks; dipotong ke `k`.
6. Ketahanan: tanpa `unwrap`/panic; label di luar rentang dan baris di luar `y` diabaikan; indeks kolom di luar kosakata dan nilai non-finite diabaikan; `ln` diamankan (`safe_ln`, sama dengan v1) sehingga kelas tanpa dokumen tidak menghasilkan NaN.
7. `lib.rs`: hanya menambah `pub mod nb_text;`.
8. Tidak ada dependensi baru (hanya `serde` yang sudah ada); `Cargo.toml`/`Cargo.lock` tidak disentuh.
9. Test baru `tests/nb_text.rs` (12 test) memakai angka golden AGENTS_V2 §6.7 persis.

## KEPUTUSAN TERBUKA / risiko
1. **Tidak ada laporan prasyarat di `plan-reports-v2/`** (folder belum ada; N2 hanya berprasyarat Tahap 1). Tahap 1 dinilai selesai berdasarkan `STWV/plan-reports/S9.md` (semua hijau di mesin pemilik) dan keberadaan API `fit/transform/CsrMatrix` di CORE. Folder `plan-reports-v2/` baru muncul (berisi `N0.md` dari agent paralel) saat laporan ini ditulis; N0 bukan prasyarat N2.
2. `train` mengembalikan `TextNbParams` (bukan `Result`) sesuai signature dokumen; `alpha` tidak divalidasi di sini (validasi 0 < α ≤ 999 ada di lapisan TS/NB). Bila `alpha ≤ 0`, `ln` diamankan dengan `safe_ln` agar tidak NaN/−inf.
3. Nilai non-finite di matriks diperlakukan 0 (bukan error); validasi nilai negatif tetap tanggung jawab pemanggil (`NB_E_TEXT_NEGATIVE`/`AM_E_TEXT_NEGATIVE`). Nilai negatif yang lolos akan ikut dijumlahkan apa adanya.
4. Complement: `C_ct` dijepit `max(0)` untuk membuang galat pembulatan `total − N_ct` pada data pecahan (TF-IDF); tidak mengubah hasil untuk data hitungan bulat.
5. Seri skor `top_k` dibandingkan dengan `total_cmp` pada skor float eksak; term dengan skor beda 1 ulp tidak dianggap seri. Pada golden, seri benar-benar identik sehingga tie-break alfabetis berlaku.
6. Derive serde pada `TextLikelihood`/`TextNbParams` ditambahkan (aditif) agar N3a/N4/A2 bisa menyimpan/mengekspor langsung; tidak melanggar kontrak.
