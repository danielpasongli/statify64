## KEPUTUSAN TERBUKA / risiko
1. **Test lama dimodifikasi inputnya.** Default `formula_standard` = Weka (§3.1), padahal characterization memakai TF log + IDF smooth (kombinasi sklearn/custom, golden "Lama"). Tanpa perubahan, test itu akan `INVALID_CONFIG`. Solusi: helper `config` di `characterization.rs` dan 2 test di `s2_pipeline.rs` ditambah `"formula_standard": "custom"`. Semua ekspektasi angka tidak berubah.
2. **Ekspektasi `stats.method` diubah** (karena §3.5 mewajibkan format baru): `"TF: log, IDF: smooth, Limit: 1000"` → `"TF: sublinear, IDF: smooth, Norm: none, Keep: 1000, MinFreq: 1"` di `characterization.rs::stats_v1_dipertahankan` dan `s2_pipeline.rs::alias_lama_menghasilkan_angka_v1_yang_sama`. Ini satu-satunya ekspektasi lama yang berubah.
3. ~~Frontend v1 belum mengirim `formula_standard`~~ — **terselesaikan oleh S6**: `config.ts::toRustConfig` sudah mengirim `formula_standard`, `normalization`, `min_term_freq` dengan enum baru, dan test stale S5 (`buildColumnData.test.ts › toRustConfig`) sudah memakai ekspektasi D6 (Weka/raw/none/none). Tidak ada perubahan tambahan yang diperlukan di S3. Sisa: uji manual UI → WASM pada S8 setelah rebuild.
4. **Definisi `empty_documents`**: dokumen tanpa satu pun token di kosakata akhir (termasuk yang tokennya terpangkas oleh Words to Keep/min_term_freq). §3.5 tidak merinci; bila pemilik ingin hanya "tanpa token sama sekali setelah preprocessing", ubah satu baris di `vectorizer.rs` (variabel `in_vocab`).
5. **Dokumen dengan norma 0 pada `doc_length`** (mis. hanya berisi kata ber-IDF 0) dikecualikan dari `avg_norm` dan tetap nol (sesuai definisi §3.2 "norma > 0").
6. **Custom + min_term_freq**: skor Σ TF×IDF dihitung dengan N dan df seluruh dokumen fit (bukan hanya kandidat), sama dengan perilaku lama.
7. `TfMethod::v1_label`/`IdfMethod::v1_label` tidak dipakai lagi (dibiarkan, tidak dihapus).
8. `avg_norm` belum disimpan di model (resep) — itu lingkup S4.
